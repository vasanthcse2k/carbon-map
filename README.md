# Carbon Map JS Web App

A lightweight web app that visualizes carbon intensity data across regions using interactive heat maps and open-source mapping libraries.

---

## **Objective**
To display the carbon intensity across regions for the latest 30-minute interval using data from a public API. This app leverages heat maps and color schemes to present the data interactively and visually.

---

## **Features**
- Interactive heat map showing carbon intensity across regions.
- Fetches the latest 30-minute data dynamically from the API.
- Free and open-source hosting for easy access.
- Fully responsive design for desktop and mobile users.

---

## **Technologies Used**
- **Framework**: React.js 
- **Styling**: CSS 
- **Mapping Library**: [OpenLayers](https://dev.to/camptocamp-geo/the-3-best-open-source-web-mapping-libraries-57o7)
- **API**: [Carbon Intensity API](https://carbon-intensity.github.io/api-definitions/#get-regional-regionid-regionid)

## **Getting Started**

### **Prerequisites**
Make sure you have the following installed:
- Node.js (v14 or later)
- npm or yarn

### **Installation**
1. Clone the repository:
   ```bash

2. Navigate to the project directory:

  cd carbon-map

3. Check Current Branch
   
   git branch

4. Install the dependencies using npm
